# Create uv environment (Local vs. Global)

**Option A: Local (Project-Specific)**
*Creates a hidden `.venv` folder in your current directory. Best for deployments and isolated repositories.*
Syntax  : uv venv --python 3.xx
Example : uv venv --python 3.12

**Option B: Global (Centralized)**
*Creates the environment in a specific permanent folder, mimicking Conda. Best for Jupyter, exploring, and daily development.*
Syntax  : uv venv --python 3.xx 
Example : uv venv --python 3.12 C:\envs\FDE1

# Activating the uv environment

**For Local environments:**
Syntax (Windows)     : ..venv\Scripts\activate
Syntax (Unix/Mac-os) : source .venv/bin/activate

**For Global environments:**
Syntax (Windows)     : \Scripts\activate
Example (Windows)    : C:\envs\FDE1\Scripts\activate
Example (Unix/Mac-os): source ~/envs/FDE1/bin/activate

# Run python file (.py) using uv

**Method 1: Standard**
Step-1 : Go to the location where file is present
Step-2 : Activate the environment
Step-3 : python .py

**Method 2: The uv shortcut (No activation required)**
*If you run this inside a project folder, uv automatically finds the local `.venv` and uses it.*
Step-1 : Go to the location where file is present
Step-2 : uv run .py
